# Статус компонентов

| Компонент | Состояние |
|---|---|
| MCP | Самостоятельный сервер stdio и Streamable HTTP |
| IACPaaS | Адаптер чтения настроенных инфоресурсов, включая нормативы для технологических газов |
| Агент | Общий разговорный цикл CLI и веб-чата с контекстом, источниками и автоматической сверкой |
| Веб-чат | SQLite-история, версии, архив и удаление диалогов, настройки модели и входа |
| Docker | Сборка веб-чата, агента и MCP в одном контейнере |
| VS Code | Пример подключения к самостоятельному MCP |
| GitHub Actions | Переносимый шаблон в каталоге `ci` |

Подключение IACPaaS и ограничения адаптера описаны в [iacpaas-integration.md](iacpaas-integration.md).

Инструкции запуска приведены в [README](../README.md). Команды проверки и покрытие тестов описаны в [verification.md](verification.md).
