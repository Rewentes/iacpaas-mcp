# Статус и границы готовности

Это описание реализованных возможностей, а не протокол приёмки конкретного развёртывания.

| Компонент | Реализовано | Что требует отдельной проверки в окружении |
|---|---|---|
| MCP | Самостоятельный stdio/Streamable HTTP, схемы, лимиты и ошибки | Подключение выбранной оболочки и её разрешения инструментов |
| IACPaaS | Реальный read-only адаптер: JWT, universal-экспорт, нормализация и происхождение | Пути и права аккаунта, совместимость текущего API, доступность сети |
| Газы | Извлечение поддерживаемых нормативных границ состава | Полнота и корректность на целевых марках и структурах онтологии |
| Агент | Общий `ConversationAgent` для CLI с моделью и веб-чата, MCP, контекст, сверка и исправление ответа | Поведение выбранной реальной модели и качество ответов на предметных сценариях |
| Веб-чат | Полная история SQLite, отдельные сводки, версии, архив, удаление, профили моделей и ресурсов | Браузеры пользователей, резервное восстановление, права на приватные файлы |
| Docker | Сборка веба, агента и дочернего MCP, постоянный том, healthcheck | Конкретный хост, ресурсы, внешняя сеть, TLS и защита удалённого доступа |
| VS Code | Конфигурация самостоятельного MCP и инструкция custom agent | Наличие совместимого чат-клиента, вход и фактические вызовы инструментов в IDE |
| CI | Действующий workflow: Linux/Windows, тесты и Docker smoke | Не проверяет реальные аккаунты платформы и провайдеров |

По умолчанию используется IACPaaS; mock включается явно и не служит запасным источником при ошибке. Запись в реальные ресурсы запрещена. Успешная автоматическая сверка не является гарантией безошибочности модели или независимой экспертизой нормативов.

Автоматические тесты используют синтетические графы и подставленные ответы внешних сервисов. Наличие Docker, зелёного CI и работающего `/healthz` не означает прохождения предметной приёмки или готовности к промышленной публикации.

Порядок работы: [запуск](../README.md) → [настройка IACPaaS](connect-iacpaas.md) → [автоматические проверки](verification.md) → [предметная приёмка](acceptance.md).
