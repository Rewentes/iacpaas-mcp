# Функциональные требования

## Сервер

- Предоставлять единый MCP API через stdio и Streamable HTTP.
- Использовать общий слой GraphService независимо от транспорта.
- Описывать аргументы и результаты типами и JSON Schema.
- Поддерживать каталог ресурсов, метаданные, подграфы, подсчёт, поиск, проверку структуры, импорт и экспорт.
- Разделять читающие и изменяющие операции; проверять доступ к записи на сервере.
- Ограничивать глубину, число элементов и размер аргументов/результатов.
- Возвращать структурированные результаты и диагностируемые ошибки.

## Клиенты

- Python CLI и VS Code используют один серверный контракт.
- Агент выбирает инструменты по их схемам и использует данные предыдущих вызовов.
- При недостатке критичных параметров требуется уточнение.
- Ошибки инструментов передаются в агентный цикл для корректировки действий.
- Количество вызовов ограничено; записи не повторяются автоматически.
- CLI запрашивает подтверждение изменения и сохраняет JSONL-трассу с маскированием секретов.

## Интеграции

Поддерживаются MockBackend с синтетическими данными `normalized-demo-v1` и read-only IACPaaSBackend с авторизацией по JWT и конвертацией universal в `normalized-iacpaas-v1`. Собственный веб-агент использует общий MCP-контракт; газовый инструмент сохраняет нормативные ограничения. Модельный профиль CLI `openai` использует OpenAI-совместимый Chat Completions endpoint; `demo` выполняет детерминированные сценарии без внешней модели.

Состояние компонентов: [status.md](status.md). Контракт инструментов: [contract.md](contract.md). Проверки: [verification.md](verification.md).
