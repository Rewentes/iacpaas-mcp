## Как поддерживать документацию

Поведение определяется исходниками и конфигурацией. При изменении сначала обновляется профильный документ из таблицы выше; остальные страницы ссылаются на него вместо копирования подробностей. README содержит быстрый запуск, а не второй полный технический справочник.

Схемы MCP сверяются с `tools/list` тестом. Действующий CI хранится только в [.github/workflows/test.yml](../.github/workflows/test.yml). Фикстуры и примеры JSON содержат синтетические данные. Личные конфигурации, экспорты, переписка и отчёты живых проверок в репозиторий не добавляются.
