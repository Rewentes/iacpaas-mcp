# Приёмка на реальном окружении

Этот документ задаёт критерии, а не утверждает, что они уже выполнены. Автоматическое покрытие описано в [verification.md](verification.md). Перед использованием на целевой платформе отдельно проверяются следующие сценарии.

| Область | Сценарий | Критерий |
|---|---|---|
| Аккаунт и ресурсы | Войти, прочитать базу газов, её онтологию и связанные базы по настроенным путям | Каждый указанный ресурс доступен; источник — IACPaaS, `mock=false`; отказ одного ресурса не скрывается |
| Ошибки доступа | Неверный пароль, недоступный путь и ресурс без прав | Различимые ошибки; нет ложного успеха, утечки секретов или перехода в mock |
| API платформы | Проверить вход, оболочку universal-экспорта, типы, ссылки и клоны | Ответы соответствуют поддерживаемому контракту; неподдерживаемое изменение формата явно отклоняется |
| Нормативные характеристики | Выбрать марки газов и сверить извлечённые значения с карточками платформы | Совпадают газ, компонент, значение, ≤/≥, единица и стандарт; суммарный предел не превращается в предел каждого компонента |
| Полнота | Использовать ресурс с внешними ссылками или ограниченную выборку | `complete`, `scope`, `warnings` не дают заявить полноту всего фонда или измеренную концентрацию |
| Реальная модель | Проверить tool calling, замечание проверяющего и исправленный ответ | Ответ относится к текущему вопросу; исправления повторно сверяются; неподтверждённый факт не публикуется как проверенный |
| Продолжение разговора | Уточнить предыдущий вопрос и довести диалог до сжатия | Сохраняется предмет обсуждения; полная история доступна, рабочая сводка не заменяет источники |
| Сбои провайдера | Отказ авторизации, лимит, таймаут и несовместимый ответ | Причина различима; сообщение сохранено; нет скрытого платного повтора или смены провайдера |
| IDE | Подключить MCP в целевой оболочке и раскрыть вызовы инструментов | Выполнены не только handshake и tools/list, но и реальные чтения базы и онтологии |
| Эксплуатация | Проверить отдельный браузер, перезапуск и восстановление резервной копии | Профили и история сохраняются; один пользователь не получает секреты другого |
| Удалённый доступ | Проверить TLS, аутентификацию, Host allowlist и сетевые ограничения | Доступ получают только разрешённые пользователи; секреты не передаются по недоверенному HTTP |

Read-only приёмка не требует изменения данных IACPaaS. Обновление версии модели, провайдера, API платформы или целевых ресурсов может требовать повторной проверки соответствующей области.

В приватном протоколе фиксируются версия приложения, окружение, модель, выбранные ресурсы, ожидаемый и фактический результат. Пароли, ключи, переписка, экспорты и результаты живых/платных проверок не публикуются в GitHub. Подтверждённое подключение одного аккаунта не доказывает переносимость прав другого аккаунта или качество всех предметных ответов.
