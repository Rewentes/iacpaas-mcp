# Демонстрация

Выполнить из корня после `uv sync --frozen`. Все примеры используют синтетический ресурс /demo/university. Demo parser выбирает только известные сценарии; свободные формулировки во всей полноте проверяются позже на реальной модели.

## 1. Два связанных вызова

```sh
uv run --frozen iacpaas-agent "найди университет и покажи метаданные" --model demo --trace traces/demo.jsonl --non-interactive
```

Ожидается tools/list, затем list_inforesources → get_inforesource. Путь второго вызова взят из результата первого. В метаданных тестового ресурса 5 вершин и 6 дуг. Фактические значения и флаги mock видны в результате; трасса содержит две записи.

## 2. Подсчёт графа

```sh
uv run --frozen iacpaas-agent "посчитай граф /demo/university" --model demo --trace traces/count.jsonl --non-interactive
```

Полный ресурс: 5 локальных вершин, 6 экземпляров дуг, из них 1 ведёт во внешнюю цель. Из root достижимы 4 локальных вершины: пятая изолирована. Эти числа относятся только к нашей фикстуре.

## 3. Подграф

```sh
uv run --frozen iacpaas-agent "покажи подграф /demo/university" --model demo --trace traces/subgraph.jsonl --non-interactive
```

Demo вызывает get_subgraph с серверными значениями по умолчанию: root, depth=2. Отдельно обратите внимание на повторную дугу, цикл и границу глубины. Для других глубин вызовите MCP tool напрямую или используйте LLM/VS Code; demo не является универсальным парсером аргументов.

## 4. Недостаточно параметров

```sh
uv run --frozen iacpaas-agent "покажи подграф" --model demo --non-interactive
```

Возвращается просьба указать путь; граф не выбирается по выдуманному идентификатору. Без --non-interactive в настоящем терминале можно ввести /demo/university в ответ на вопрос.

## 5. Ошибка и восстановление

```sh
uv run --frozen iacpaas-agent "покажи метаданные /missing/resource" --model demo --trace traces/recovery.jsonl --non-interactive
```

Трасса содержит каталог, реальный not_found и чтение известного ресурса из каталога. Это сценарий восстановления на одной фикстуре. При неоднозначном выборе ресурса требуется уточнение.

## 6. Отказ записи

```sh
uv run --frozen iacpaas-agent "измени комментарий /demo/university" --model demo --trace traces/denied.jsonl --non-interactive
```

Изменение отклоняется клиентом. Отдельные протокольные тесты вызывают пишущий tool напрямую и доказывают независимый запрет на сервере при выключенной политике.

## 7. Подтверждённая mock-запись

Только из интерактивного терминала, на синтетическом ресурсе:

```sh
IACPAAS_ALLOW_WRITES=1 IACPAAS_WRITABLE_PREFIX=/demo/ uv run --frozen iacpaas-agent "измени комментарий /demo/university" --model demo --trace traces/write.jsonl
```

Проверьте аргументы и введите yes. Меняется комментарий root, а не реальные данные IACPaaS. Новый stdio-запуск заново загрузит фикстуру. Проверка TTY-ветки в автоматическом smoke-тесте использовала псевдотерминал и тестовый ввод yes; это не запись решения реального человека.

## 8. HTTP и два клиента

Задайте одинаковый MCP_HTTP_TOKEN в двух терминалах безопасным способом. В первом:

```sh
uv run --frozen iacpaas-mcp --transport http --host 127.0.0.1 --port 8000
```

Во втором:

```sh
uv run --frozen iacpaas-agent "посчитай граф /demo/university" --model demo --transport http --url http://127.0.0.1:8000/mcp --trace traces/http.jsonl --non-interactive
```

Без правильного токена HTTP возвращает 401. Результат count_graph совпадает с stdio. Реальный HTTP-прогон сохранён в examples/transport-smoke.json без токена.

## 9. Три обязательных сценария VS Code

Настройка приведена в agent.md. Выберите IACPaaS Mock Explorer и покажите:

1. «Найди университет и покажи его метаданные».
2. «Найди университет и посчитай вершины и дуги его графа».
3. «Найди университет и покажи подграф от root глубиной 2».

Показывайте фактические вызовы инструментов, а не только итоговый текст. Затем можно дополнительно показать неизвестный путь и ограничение глубины.

Эти три сценария должны быть выполнены **непосредственно в вашей IDE**. Существование файлов конфигурации и успешный CLI не заменяют этот этап приёмки.
