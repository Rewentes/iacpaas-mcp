| Проверка | Результат |
|---|---|
| Установка `uv sync --frozen` | успешна, включая не-editable установку |
| Ruff check и format check | без ошибок |
| pytest, Python 3.14.7 | 48 passed |
| pytest, Python 3.13.5 | 48 passed |
| Запуск wheel вне каталога исходников | demo.json включён в пакет, CLI работает |
| MCP stdio и HTTP | initialize, tools/list, tools/call работают |
| HTTP без токена | 401 |
| count_graph через stdio и HTTP | одинаковые результаты |

| Запись из неинтерактивного CLI | отказ |
| CLI с TTY-подтверждением | изменение mock-данных после ввода yes |
| Некорректный путь | not_found и ограниченное восстановление |
| Недостающий путь | запрос уточнения |
| Выбор неподключённого IACPaaS backend | unsupported_backend |

## Покрытие регрессий

- Секреты маскируются до обрезки строк, включая значение на границе длины.
- Уже применённая запись с большим результатом возвращает ограниченное успешное подтверждение и корректный статус аудита.
- Если подтверждение не помещается в бюджет, update/import отклоняются до изменения.
- Большие ответы чтения возвращают limit_exceeded.
- Проверяются семантика графа, повторные дуги, цикл, внешние цели, лимиты, схемы, запрет записи и восстановление клиента.

## Границы проверки

- IACPaaS API пока не подключён; права платформы и форматы universal/meta/simple требуют отдельных интеграционных тестов.
- Реальный LLM endpoint не проверен. Контракт адаптера проверяется тестовым HTTP transport.
- Конфигурации VS Code подготовлены; GUI, trust prompts и ввод токена требуют ручной проверки.
- Windows/macOS и выполнение на Python 3.11/3.12 не проверены. Trace использует POSIX-защиту файла.
- GitHub Actions представлен шаблоном в `ci/`; приведённые результаты относятся к локальным запускам.

## Ограничения

MockBackend не сохраняет изменения между процессами. Demo parser поддерживает ограниченный набор сценариев. Redaction — best effort, поэтому перед публикацией трассы необходимо проверить. При неизвестном сетевом исходе записи требуется read-back без слепого retry.
