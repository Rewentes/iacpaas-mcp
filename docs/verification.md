# Проверка проекта

Исходные тесты находятся в `tests/`; они используют синтетические ресурсы и подставленные ответы модели. Команды:

```sh
uv sync --frozen
PYTHON_DOTENV_DISABLED=1 uv run --frozen pytest -q
uv run --frozen ruff check .
cd frontend && npm ci && npm run build
```

На Windows те же проверки выполняются в PowerShell:

```powershell
uv sync --frozen
$env:PYTHON_DOTENV_DISABLED = "1"
uv run --frozen pytest -q
uv run --frozen ruff check .
```

Прямой запуск веб-чата проверен на Windows 11 в PowerShell: `uv sync --frozen`, `Copy-Item .env.example .env` и `uv run --frozen --env-file .env iacpaas-web --host 127.0.0.1 --port 8080`. Страница `http://127.0.0.1:8080` открывается, `/healthz` и `/api/me` отвечают, MCP доступен по stdio и HTTP, команда из `.vscode/mcp.json` выполняет MCP-хендшейк. Docker Compose на Windows не проверялся: для него нужен Docker или CI-задание.

Проверяются MCP stdio/HTTP, схемы и ограничения, графовые операции, политика записи, клиент CLI, обработка ошибок и происхождение фактов. Переносимые регрессии в `tests/extended/` охватывают разговорный цикл, сжатие контекста, цитаты с диапазонами, передачу полных документов проверке, профили провайдеров, секреты IACPaaS, архив/восстановление/удаление и сохранность веток переписки.

Браузерные проверки на синтетических данных покрывают промежуточные события, Markdown, ссылки, редактирование/перегенерацию, темы, прокрутку, мобильную ширину и действия с диалогами. Они не требуют платного обращения к модели.

Для живой проверки отдельно нужны собственные данные входа IACPaaS, разрешённые пути ресурсов и ключ выбранного провайдера. Переносимость реальных прав пользователя и доступность внешней модели локальные тесты не доказывают. Автоматическая модельная сверка может дать ошибочную оценку; отчёт и первоисточники доступны пользователю. Факт проверки не означает независимую экспертизу нормативов.

`.github/workflows/test.yml` (и его копия `ci/github-actions.yml.example`) запускает тесты на Ubuntu и Windows, а также Docker Compose smoke-проверку. Секреты, личная переписка, трассы и экспорты ресурсов не входят в репозиторий.


## Согласование ответа и контекст

Регрессии `tests/extended/test_portable_reconciliation.py` проверяют:

- передачу автору числовых, нормативных и смысловых замечаний;
- исправление неверного ответа и пересмотр ошибочного вердикта проверяющим;
- дополнительные MCP-чтения без сброса общего лимита;
- ограничение числа раундов и запрет публикации повторно выдуманного числа;
- содержательное уточнение вместо спорного факта и сохранение полезного частичного ответа;
- несколько вопросов в реальном веб-диалоге с полной историей SQLite;
- сохранение последнего предмета обсуждения после сжатия и удаление старых ID только из рабочего контекста;
- отсутствие ложной отметки об успешной проверке при недоступном проверяющем.

Эти сценарии используют подставленные модели и синтетический MCP. Они проверяют цикл и передачу контекста, но не заменяют отдельную разрешённую проверку поведения выбранной внешней модели.

## Живая синтетическая проверка — 16 ноября 2026

Проверена выбранная в веб-чате модель `deepseek/deepseek-v4.1-flash-1017` через OpenRouter. Использовались только вымышленные карточки газов и новая синтетическая переписка; пользовательские ресурсы IACPaaS и настоящие сообщения не отправлялись.

Проверены восемь сценариев: сравнение чистоты, объяснение знака из предыдущего ответа, переход к азоту тех же марок, смена газа, исправление намеренно неверной границы, отклонение неподтверждённого утверждения, пересмотр намеренно ошибочного вердикта проверяющего и уточнение после двух сжатий истории. В трёх сценариях ошибки были специально внесены проверочным стендом, а исправление/последующая сверка выполнялись реальной моделью.

Проверка обнаружила дефект: обновление остатка MCP-бюджета перезаписывало системное сообщение и удаляло инструкции исправления. Теперь они сохраняются на каждом шаге раунда, включая дополнительные чтения. Промпты автора и проверки также ограничивают ответ запрошенными свойствами; достоверные, но лишние сведения не объявляются неподтверждёнными.

После исправления повторно проверены все восемь сценариев. Конкретные значения и границы сверены с фикстурой. Один строковый критерий стенда дал ложное срабатывание: модель процитировала ошибочную фразу с явным отрицанием, а проверка искала её подстроку. Этот результат отдельно просмотрен и зафиксирован; исходный автоматический результат сохранён.

Суммарно все диагностические проходы: 85 запросов, стоимость по `usage.cost` — **$0.04669557948** при разрешённом пределе $0.10. Перед каждым вызовом резервировалась верхняя оценка стоимости. Приватный подробный отчёт сохранён вне репозитория. Локальный набор после правки: 188 тестов. Эти результаты относятся к указанной модели и синтетическим сценариям, а не доказывают безошибочность на любых данных.
