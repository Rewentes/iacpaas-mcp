# Интерфейс чата

## Компоновка и оформление

История диалогов расположена слева, сообщения и ввод — по центру. Пустой чат показывает приветствие, поле ввода и два случайных примера из десяти фиксированных вопросов. Нажатие на пример заполняет поле ввода.

Провайдер, модель, API-ключ, вход IACPaaS и пути баз/онтологий находятся в настройках. Типовые пути заполнены заранее, изменения сохраняются для владельца браузерной сессии. Сохранённые секреты не возвращаются браузеру; поля пароля и ключа остаются пустыми. Проверка доступа к платформе читает все настроенные ресурсы без запроса к модели; доступная база при недоступной онтологии не считается успешной проверкой.

Контролы используют [JetBrains Ring UI](https://github.com/JetBrains/ring-ui), шрифт Inter загружается локально. Типографика и цвета заданы общими токенами. Доступны светлая, тёмная и системная темы с сохранением выбора браузером. Анимации учитывают `prefers-reduced-motion`.

Переписка и список диалогов прокручиваются отдельно. При чтении старых сообщений поступление ответа сохраняет позицию; к концу можно перейти кнопкой. На узком экране боковая панель открывается отдельно и закрывается кнопкой, Escape или нажатием на область справа по всей высоте экрана. Таблицы и длинные технические значения имеют внутреннюю горизонтальную прокрутку.

## Действия с сообщениями и диалогами

«Изменить запрос» открывает редактор; отправка создаёт новую ветку с сообщениями до выбранного вопроса. «Сгенерировать снова» создаёт новый ответ в отдельной версии. Исходные сообщения и источники сохраняются. Создание версии не вызывает модель; новый цикл начинается при её отправке. Автоматических платных повторов нет.

Меню «⋯» и правая кнопка мыши по диалогу открывают одни действия: «Переименовать», «В архив»/«Восстановить» и «Удалить». Архив доступен отдельной кнопкой; восстановление возвращает диалог в активный список. Архивная история доступна для чтения. Удаление требует подтверждения и очищает только выбранный диалог, сохраняя отдельные версии. Во время незавершённого запроса эти действия блокируются.

Ход работы показывается по мере получения событий и сохраняется с ответом. Markdown выводится безопасными DOM-узлами: HTML модели не исполняется. Источники и отчёт автоматической сверки раскрываются отдельно; доступны полные результаты MCP и кликабельные ссылки, включая диапазоны свидетельств.

Контракт HTTP, хранение и рабочий контекст описаны в [web.md](web.md), профили модели — в [model-providers.md](model-providers.md).


## Названия диалогов

После первого вопроса новый диалог получает короткое название из текста этого вопроса. Отдельного запроса к модели для названия нет. Существующие диалоги с общим названием получают тему из первого сохранённого вопроса при обновлении.

В меню `⋯` или по правой кнопке мыши рядом с диалогом доступно «Переименовать». Название можно изменить и у архивного диалога. Ручное название сохраняется после перезагрузки и следующих сообщений. В окне есть поле, сохранение и отмена; при ошибке введённое название остаётся для повторной попытки.

Меню также открывается клавишами Shift+F10 или клавишей контекстного меню на строке диалога. Стрелки переключают действия, Escape закрывает меню. Щелчок вне меню и прокрутка списка закрывают его.
