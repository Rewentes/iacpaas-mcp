# Подключение IACPaaS

Read-only адаптер реальной платформы реализован. Настройка, HTTP-контракт, таблица операций MCP, проверки и ограничения находятся в [iacpaas-integration.md](iacpaas-integration.md).

Нужны логин, пароль и точные пути доступных ресурсов в приватном `.env`. Приложение получает JWT через вход и читает universal-экспорты. Используйте `IACPAAS_BACKEND=iacpaas`; отсутствие доступа и ошибки не подменяются mock-данными.

Запись в реальные ресурсы отключена. Для будущей записи необходимы отдельная копия ресурса, проверка прав, явное подтверждение, контроль неизвестного исхода и read-back. Текущая политика записи относится только к volatile mock.
