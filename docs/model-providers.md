# Провайдеры и подключение модели

Модель выбирается в веб-чате. Настройки хранятся на сервере отдельно для владельца браузерной сессии; смена провайдера не должна передавать его ключ другому провайдеру. Очистка cookie лишает доступа к прежней анонимной идентичности — это не полноценная система аккаунтов.

## API-подключения

- **OpenRouter**: API-ключ, модель по её точному идентификатору, endpoint `https://openrouter.ai/api/v1`.
- **OpenAI API**: отдельный API-ключ, endpoint `https://api.openai.com/v1`.
- Подписка ChatGPT не считается API-ключом OpenAI; подключение Codex выполняется отдельно.

Ключ вводится в поле типа password. После сохранения API сообщает только о наличии ключа, не возвращает его значение. Ключи не записываются в сообщения, tool events, frontend-код или localStorage. Поле с сохранённым ключом остаётся пустым. Настройки SQLite защищены правами файла; это не обещание шифрования ключей на диске.

Сохранение настройки и получение каталога моделей не подтверждают работоспособность модели. Кнопка проверки выполняет небольшой настоящий запрос и может расходовать лимит провайдера. Пустой ключ, ошибка сети, отсутствие доступа и неподдерживаемая модель должны отображаться как ошибки, без автоматического перехода к другому провайдеру.

При доступе к приложению по HTTP через локальную сеть ввод ключа не защищён TLS. Такой режим предназначен только для доверенной сети; для недоверенного доступа нужен HTTPS и полноценная аутентификация приложения.

## Подписка ChatGPT / Codex

Используется официальный `codex app-server`, а не копирование токенов из Hermes и не выдача подписки за API-баланс. Вход запускается пользователем в настройках. Device-code flow выдаёт ссылку OpenAI и одноразовый код; пользователь подтверждает вход на сайте OpenAI. Код и OAuth-токены не нужно отправлять в чат.

Для каждого владельца сессии создаётся отдельный `CODEX_HOME`; общий `~/.codex` и авторизация Hermes не используются. Статус авторизации и доступность выбранной модели — разные проверки. Каталог `model/list` сам по себе не подтверждает право выполнить запрос.

Официальный CLI устанавливается отдельно, например `npm install -g @openai/codex`. При нестандартном расположении задайте `CODEX_BIN`. CLI и его протокол нужно проверять при обновлении; совместимость текущей реализации проверяется отдельно от авторизации конкретной подписки.

Решения модели проходят через собственный агентный цикл приложения: именно он вызывает MCP, проверяет данные и управляет контекстом. Codex не должен получать независимый доступ к shell, файловой системе, другим MCP, браузеру, плагинам или хукам серверного пользователя. Если безопасный режим не установлен, выполнение должно завершаться явным отказом, без небезопасного fallback.
